# PR 的待确认焦点可能在三连按中重复使用

State: closed
Scope: 现有实现已覆盖

PR 的第二次请求若指向 Hyprland 仍报告为 active 的窗口，会保留第一次的 `inFlightAddress`。第三次可能继续按过期目标计算，得到 `B、A、A`。

## 验证结果

隔离测试执行现有 `Switcher.qml` 的选择、派发和焦点回报逻辑。保持 Hyprland 的初始报告为 A，三次快点依次选择 B、A、B。三次请求都还在排队、较早的 B 回报在第二次请求派发前或后到达，以及合成器省略中间回报的情况下，结果均正确。另验证目标在派发前后关闭的回退，以及外部焦点清除待确认请求。关联 #02、#03。

在已安装插件上用两个临时应用通过 IPC 复测。12 ms 和 25 ms 间隔下，单次、双次和三次快点各跑三轮，共 18 轮全部到达预期窗口。测试结束后关闭两个临时窗口并恢复原焦点。无需新增运行代码。
