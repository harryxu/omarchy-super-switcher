# 应用图标首帧可能跳变尺寸

State: closed
Scope: 已部署并复测

PR 报告图标会先按回退尺寸显示，随后应用已测得的边界。作者提出同步使用已有几何缓存，并将测量结果跨 Shell 重启保存。

## 验证与处理结果

渲染回归复现了已有缓存时的问题：带透明留白的图标再次创建后，尺寸数据仍要等异步回调才生效。现在创建图标和切换图标来源时都会同步读取内存缓存。冷缓存时，图标在测量完成后才以适配后的尺寸显示；若触发 120 ms 兜底，当前图标保持初次显示的尺寸，迟到的测量结果供下次打开使用。

几何缓存仅存于内存，Shell 重启后重新测量。测试覆盖三档缩放、冷缓存、重新打开、来源切换、默认图标回退，以及测量迟到时保持约 56 px 的已显示图标尺寸。

已部署并重启 Omarchy Shell。用已安装的组件在 Wayland 上跑过同一套渲染测试，并验证两个 IPC 入口和 12 条快捷键绑定。
