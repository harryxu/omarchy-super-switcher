# Triage labels

Use the same strings for GitHub labels and local ticket statuses.

| Role | Label or status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | The maintainer needs to evaluate the ticket. |
| `needs-info` | `needs-info` | The ticket is waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | The ticket is specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The ticket requires human implementation. |
| `wontfix` | `wontfix` | The maintainer decided to close the ticket without implementing it. |
